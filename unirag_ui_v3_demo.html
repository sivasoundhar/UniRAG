What's the recommended torque spec for the M8 mounting bolts?
rewrite→ hybrid retrieve→ rerank→ compress→ generate
The bracket assembly spec calls for M8 mounting bolts torqued to 24–27 Nm, using a lubricated thread condition per the fastener table. Re-torque after the first thermal cycle is recommended.
